# 评测结果目录

这里放**被报告引用**的原始数据，不放过程产物。

## 命名

```
<被测对象>-<时间戳>.json / .md     单次评测（M2）
denoise-<对象>-<复核方>-<时间戳>.*  降噪实验（M4）
M2-matrix.md / M4-denoise.md       汇总报告，正文引用上面的原始文件
```

时间戳是运行时刻，`--label` 可以加前缀区分变体。

## 保留策略

只留最终用于报告的那几份。中间调参、冒烟、重复跑的结果一律不入库 ——
它们对读者没有价值，只会让目录越来越难判断「哪个数才是准的」。

基准口径变化（例如负例从 13 扩到 65）时，旧结果整体移入
`archive/<口径>/`，保留可查但不与当前数字混排。当前归档：`archive/n13/`。
